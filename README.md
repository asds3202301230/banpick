# 내전 밴픽

리그 오브 레전드 토너먼트 드래프트 방식 밴픽 시뮬레이터입니다. 외부 패키지 없이 Node.js(18 이상)만으로 동작합니다.

## 기능

- 모드: SOLO(혼자 양 팀 진행), 1:1(팀장 2명), 5:5(플레이어 10명, 각자 자기 순서에만 선택 가능)
- 방 생성 후 블루팀 / 레드팀 / 관전자 링크를 각각 공유
- 실시간 동기화 (SSE), 턴당 30초 타이머 (시간 초과 시 밴은 건너뛰기, 픽은 무작위)
- 챔피언 이름 한글 표시, 한글 검색 및 초성 검색 (예: `ㅇㅅ`)
- 라인별 챔피언 보기 (탑/정글/미드/원딜/서폿)
- 결과 화면 PNG 이미지 저장
- 챔피언 이름/이미지는 Riot Data Dragon에서 최신 패치 기준으로 자동 로드

## 실행

```
node server.js
```

브라우저에서 http://localhost:3000 을 엽니다.

환경변수: `PORT`(기본 3000), `TURN_SECONDS`(기본 30)

## 테스트

```
SKIP_CHAMPS=1 PORT=3100 node server.js &
node test.js
```

## 다른 사람과 함께 쓰려면

방 링크는 접속한 주소 기준으로 만들어지므로, 서버를 외부에서 접근 가능한 곳에 올려야 합니다.
Render, Railway, Fly.io 같은 Node 호스팅에 올리면 되고, `node server.js`를 시작 명령으로 지정하세요.
방 정보는 메모리에만 저장되므로 서버를 재시작하면 진행 중인 방은 사라집니다.
리버스 프록시(nginx 등) 뒤에 둘 때는 SSE를 위해 버퍼링을 꺼야 합니다.

## 참고

- 라인 분류는 `lanes.js`에 있는 대략적인 목록입니다. 신규 챔피언이나 메타 변경은 해당 파일에 Data Dragon ID를 추가/삭제하면 됩니다. 목록에 없는 챔피언은 "전체"에서만 보입니다.
- 이 프로젝트는 Riot Games와 무관한 비공식 도구입니다. 챔피언 이미지는 Riot의 Data Dragon CDN에서 불러옵니다.
